# Convince the AI Judge to Visit Your House

make.fun bounty entry — one image of a letter inviting the AI judge to
come visit: the best chair by the window, tea that never gets cold, a
garden where the tomatoes argue with the sunflowers, chocolate cake,
Wi-Fi, and a cat who has already approved of you.

- `main.py` (pure Python standard library, no third-party packages)
  writes one 1024x1024 PNG to `/output/entry.png`.
- Deterministic: two runs produce byte-identical output.

Run it: `python3 main.py` (writes `/output/entry.png`).
